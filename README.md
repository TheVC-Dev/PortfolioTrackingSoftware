# portfolio management software

Helps track and analyze investment assets across multiple portfolios and Accounts. 

## Features 
- Create and manage Clients
- Keep track of and manage multiple portfolios for client
- add, manage and remove stocks in portfolios
- Retrieve latest market prices
- Fully functioning menu interface;
- Overveiw of how individual portfolios or stocks are performing for client
- Display total growth/loss for client
- Save/load client assets from file
